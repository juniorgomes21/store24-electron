# Store24h Desktop

Electron desktop application developed for the Store24h platform.

The application combines Electron with React and TypeScript to provide a desktop-based interface integrated with Store24h backend services.

## Features

- Desktop application built with Electron
- React-based user interface
- TypeScript development
- Backend API integration
- Client-side routing
- Reusable UI components
- Responsive interface
- Desktop application packaging

## Technologies

- Electron
- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router
- Electron Router DOM
- Material UI
- Electron Builder

## Architecture

The application combines a web-based React interface with the Electron runtime.

The main layers include:

- Electron application process
- React renderer
- UI components
- Application routing
- API communication
- Desktop packaging

The React frontend communicates with backend services through HTTP APIs using Axios.
